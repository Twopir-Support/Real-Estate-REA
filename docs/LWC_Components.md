# Lightning Web Components — TC Commercial Real Estate

The app has 18 components: 16 exposed and 2 internal. They use SLDS styling and
base components only, so there are no external libraries or CDNs. Placement
targets are generated by `scripts/lwc-meta.js`.

| Component | Where | What the user does | AscendixRE counterpart |
|---|---|---|---|
| `tcPropertyDashboard` | TC Home | Sees KPI tiles (properties, occupancy, available SF, pipeline and weighted fees, won this year, expiring SF, open inquiries) and 4 charts. Filters by market and property type. | Dashboards |
| `tcDealPipeline` | Deal Pipeline tab | Kanban board of open deals by stage, with count, fee and SF per column. Drag a card, or use its menu, to change stage. Filter by deal type or "my deals". Overdue close dates are flagged. | Kanban pipeline |
| `tcPropertySearch` | Property Search tab | Filters by type, class, city, market, size, availability and rate. Radius search from coordinates or from a selected property. Results grid plus `lightning-map` pins. Criteria are remembered in the browser. | Ascendix Search map search (radius) |
| `tcCommissionDashboard` | Commission Dashboard tab | Projected, earned, paid and balance totals; gross by broker; commissions by status; house share (privileged users only); earned and unpaid list | Commission reporting |
| `tcPropertyDetail` | Property page | Hero image, address, chips, occupancy gauge, 10 key stats, map | Property highlights and map |
| `tcStackingPlan` | Property page, Stacking Plan tab | Floors listed top-down, with units sized by SF. Leases are coloured by expiration year under an "LXD" legend. Available space uses the configured vacancy colour. Unrecorded floor area is hatched. Filter by expiration year; click a block to open the record. | Stacking Plan |
| `tcImageViewer` | Property, Listing and Availability pages | Gallery of the primary image URL plus uploaded image files; upload new images | Image Viewer |
| `tcDocumentGenerator` | Property, Listing and Inquiry pages | Choose a flyer, lease comp report or tour book; preview it, or generate a PDF saved as a File | Composer (basic) |
| `tcRelationshipGrid` | Property, Listing, Deal, Account and Contact pages | Lists internal users and their roles on the record; adds new ones | Relationship Grid |
| `tcScorecard` | Deal, Property, Lease, Listing and Account pages | Up to 5 KPI tiles per record | Scorecard |
| `tcRentTable` | Deal and Lease pages, Rent Table tab | View periods, edit inline (dates, rate, rent per month, free rent), generate from terms with a confirmation, see review warnings and the total | Rent Table |
| `tcCommissionGrid` | Deal page, Commissions tab | Shows gross fee, net deal fee and inside-split totals. Edit fee % inline. Bulk add up to 30 rows of one type, with record pickers. House and Net columns appear only for privileged users. | Commission dialog and bulk entry |
| `tcTermSheetCompare` | Deal page, Term Sheets tab | Lender quotes side by side; best rate, fee and LTV highlighted | Term sheet comparison |
| `tcInquiryMatches` | Inquiry page, Matching Listings tab | Find Matches scores active listings 0–100 with reasons; add the selected ones as Prospective Listings | Prospective Listings (TC adds the scoring) |
| `tcCloseDeal` | Deal quick action **Close Deal** | Won or Lost, close date, actual value, lost reason. Shows what will be created and which fields are missing, then links to the records created. | Close Deal dialog |
| `tcConvertInquiry` | Inquiry quick action **Convert** | Shows the account and contact that will be reused or created. Choose the listing for the deal, convert, and land on the deal. | Convert Inquiry |
| `tcChart` | internal | Accessible horizontal bar chart in HTML and CSS | – |
| `tcUtils` | internal | Currency, number, percent and date formatting; error reduction; expiration colour scale | – |

## Pages

These pages are generated by `scripts/ui-meta.js`:

- **Record pages.** Each is active only inside the TC app, so the SDO apps are
  unaffected.
  - Property: Property 360 above a Details / Related / Stacking Plan tabset, with
    Images, Documents and Relationships in the sidebar.
  - Deal: Scorecard above Details / Related / Rent Table / Commissions / Term
    Sheets, with Relationships in the sidebar.
  - Lease: Scorecard above Details / Related / Rent Table.
  - Listing: Scorecard above Details / Related, with Images, Documents and
    Relationships in the sidebar.
  - Inquiry: Details / Related / Matching Listings, with Documents in the
    sidebar.
  - Availability: Details / Related, with Images in the sidebar.

  Every record page also has the activity panel in the sidebar.
- **App pages, each with its own tab:** TC Home, Deal Pipeline, Property
  Search, Commission Dashboard.

## Accessibility and UX notes

- Every interactive block has a keyboard handler and a visible focus outline.
- The stacking plan exposes its blocks as `role="button"`.
- Charts include text values, so they don't rely on colour alone.
- Loading, empty and error states are written out for each component.
- Errors use `reduceErrors` to surface the actual validation message.
